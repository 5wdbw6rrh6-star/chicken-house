# نظام المطعم (كاشير + فواتير + الداخل والخارج)

البيانات بتتحفظ **على السيرفر** في الملف `data/db.json`، فكل الأجهزة اللي بتفتح الموقع بتشوف نفس الفواتير والأصناف والحركات.
مفيش أي مكتبات تتثبت: محتاج بس Node.js نسخة 16 أو أحدث.

## التشغيل

    node server.js

وافتح: http://localhost:3000

## إعدادات (متغيرات بيئة)

| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| PORT | رقم البورت | 3000 |
| APP_PASSWORD | كلمة سر للموقع كله (اسم المستخدم أي حاجة) | بدون |
| DATA_DIR | مكان حفظ البيانات | ./data |

مثال: `APP_PASSWORD=MyStrongPass PORT=8080 node server.js`

## النشر على سيرفر (VPS)

1. ارفع الفولدر وثبّت Node.js.
2. شغّله بشكل دائم بـ pm2:

       npm i -g pm2
       APP_PASSWORD=MyStrongPass pm2 start server.js --name resto
       pm2 save && pm2 startup

3. حط Nginx قدامه مع شهادة HTTPS (Let's Encrypt)، وخلّي `proxy_pass http://127.0.0.1:3000;`.

استضافة Node جاهزة (Render, Railway, ...): اربط المشروع، أمر التشغيل `node server.js`، وفعّل **Persistent Disk/Volume** واضبط `DATA_DIR` عليه.
لو الاستضافة بتمسح الملفات مع كل نشر، البيانات هتضيع من غير الـ volume.

## النسخ الاحتياطي
انسخ الملف `data/db.json` بشكل دوري. استرجاعه = رجّع الملف مكانه وأعد تشغيل السيرفر.

## ملاحظات
- حسابات الفاتورة (الخصم والخدمة والضريبة) بيعملها السيرفر، فالمتصفح مش بيقدر يغيّر الأسعار.
- الصفحة بتحدّث نفسها كل 8 ثواني، فلو كاشير سجل فاتورة تظهر عند الباقي.
- لو الموقع هيتفتح من الإنترنت، لازم تحط `APP_PASSWORD` وتستخدم HTTPS.
